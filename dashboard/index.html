What this is

Mini-NMS is a network operations tool running against a fixed simulated network of 5 Cisco devices. It reads their real IOS configurations to audit them, monitor live state, and troubleshoot connectivity faults. You're exploring a built-in sample network — you can't upload your own configs here.

The network

  • Routers: r1, r2 (OSPF core)
  • Switches: sw1, sw2 (VLAN 10 = users, VLAN 20 = servers)
  • Firewall: fw1 (edge)
  • Hosts you can reference: USER-PC-1, USER-PC-2, USER-PC-3, SERVER-APP-1 (on sw1); USER-PC-4, SERVER-APP-2, SERVER-DB-1 (on sw2)

What you can do

  • Audit — scroll to Config Audit to see security, correctness, and drift findings, each with a fix. (Already computed — nothing to click.)
  • Monitor — Live Status shows each interface; use "Inject: core link down" then "Clear faults" to see the network react.
  • Troubleshoot — enter a source and destination and click Diagnose. Source/dest can be a host name (e.g. SERVER-APP-1), an IP (e.g. 10.10.10.50), a device:interface (e.g. r1:GigabitEthernet0/0), or the word gateway. The tool walks the network layer by layer to the root cause.

Try these

  • SERVER-APP-1 → gateway — a VLAN misconfiguration (server cut off at the trunk)
  • SERVER-DB-1 → gateway — a shut-down switch port
  • USER-PC-4 → 10.20.20.10 — a subnet overlap between two devices
